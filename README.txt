HARRISON & TASHA — ENGAGEMENT GALLERY

HOW TO OPEN
1. Unzip this folder.
2. Open index.html in a web browser.

HOW TO PUBLISH WITH GITHUB PAGES
1. Create a new GitHub repository.
2. Upload everything inside this folder, keeping the images folder intact.
3. In repository Settings > Pages, publish from the main branch and root folder.
4. GitHub will provide the live gallery link.

The gallery includes:
- Mobile-friendly layout
- Full-screen image viewer
- Individual image downloads
- A Download All button
